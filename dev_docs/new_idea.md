k-os внешне

- это демон/сервис где происходит вся работа
- может еще быть демон для root
- cli для управления и статуса
- GUI приложение - трей иконка со статусом и начальный экран для подключения к своей сети
- написано на rust, gui на slint



k-os внутри

- в нем запущены сервисы и драйверы
- сама система тонкая, по сути выходы во вне и платформа для серсисов и драйверов
- имеет свои хранилища для программ, кэша, логов и предоставляет программам и сервисам свои папки
- управляет пользовательской домашней папкой
- файлы шифруются , включая названия папок и файлов через односмторонний хэш
- единые llm и stt модели в системе для исползвания любыми приложениями

- навеное половательскую папку не шифровать если пользватель сам не хочет, а шифровать системные файлы. если шифровать польваельскую папку то не будет доступа с хостовой системы



приложения

- приложения выполняются в хостовой системе как обычные приложения
- приложения используют наш sdk который связывается с k-os максимально эффективным способом с минимальными задержками
- приложения не испльзуют доступ к файловой системе хоста или выход в сеть, все делают через k-os
  - выод в сеть, файлы пользователя, логи, кэш и тд
- можно для попрулярных приложений делать форки в которые встраивается поддержка k-os чтобы они работали с его файлами и через сеть
- приложение включает в себя все библиотеки и зависимости, включая наш sdk
- может писаться на любом языке



менеджер приложений V1

- свой сервис регистрации приложений, где разрабы заводят аккаунты и публикуют приложения и обнволения
- но сами файлы там не хранятся, они хранятся в релизах github, gitlab и тд
- в сети юзера выбирается одно устройство для обнаружения обнволений и оно его скачивает и раздает по всей своей сети
- так же пользователи могут включать ноды для ретрансляции приложений и раздавать всем своим контактам
- приложения устанавливаются в папку которую контролирует k-os , фйлы не шифрованные чтобы могли запусмкаться хостовой системой, но можно перед запуском проверять хэш суммы файлов
  - ‼️ вобще тут нужно подумать по части защиты от подмены файлов
