# Облачная нода

Статус: перенесено из прежних документов, требует ревизии.  
Назначение: описать headless-ноду пользователя: назначение, гарантии, отличия от device-ноды и от relay.

Связанные документы: [профиль и ноды](../02-architecture/02-profile-and-nodes.md), [NAT и достижимость](../07-onboarding/02-nat-and-reachability.md), [взаимодействие пользователей](../08-federation/01-model.md).


Headless-нода: ядро K-OS без Tauri, WebView и системного UI. Ставится пользователем на собственный сервер или VPS.

Cloud node:

- является **полноправным доверенным членом профиля** и владеет актуальными data encryption keys;
- по умолчанию хранит полную реплику replicated state и полный набор blobs;
- исполняет workers и system services, для которых разрешено удалённое размещение;
- является предпочтительным leader-кандидатом для `cluster-singleton` и точкой rendezvous для Internet-канала;
- **не запускает UI приложений**. Удалённый доступ к UI не проектируется: приложение и его состояние реплицированы, поэтому UI запускается локально на том устройстве, которое пользователь взял в руки.

Прямое следствие доверия: компрометация хоста cloud node означает компрометацию данных профиля. Поэтому cloud node предполагается на подконтрольном пользователю оборудовании, а для сценария «не доверяю хостингу» существует роль `relay`.

Отдельный namespace может быть помечен как `no-cloud` — тогда он не реплицируется на cloud nodes ценой доступности при выключенных личных устройствах.

Система обязана работать без cloud node. Cloud node улучшает доступность и время сходимости, но не является обязательным компонентом.


## Требует дополнения

Из описания продукта следуют роли облачной ноды, не отражённые в перенесённом тексте:

- удобная точка подключения к сетям других пользователей и приёма подключений от них;
- источник истины при синхронизации файлов за счёт постоянной доступности;
- маршрутизация запросов внутри сети пользователя и обработка внешних запросов;
- шлюз в интернет для нод, у которых нет прямого доступа;
- постоянный адрес, снимающий проблему достижимости за NAT;
- альтернатива облачной ноде — нода на домашнем сервере, постоянно включённая.

Отдельный вопрос: чем облачная нода отличается от headless-ноды умного дома, которая тоже
работает без экрана, но обладает подключённым оборудованием, см.
[устройства и IoT](../09-devices/01-model.md).
