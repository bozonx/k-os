# Словарь терминов

Статус: готов  
Назначение: дать единые определения терминам, используемым во всех документах, и указать,
где термин раскрыт подробно.

Правило: термин используется только в том значении, которое зафиксировано здесь.
Синонимы не вводятся; устаревшие названия перечислены отдельно.

## Среда и устройства

| Термин | Значение | Подробно |
|---|---|---|
| **Profile** (профиль) | персональная среда пользователя: установленные пакеты, права, реплицируемые namespaces, доверенные устройства | [профиль и ноды](../02-architecture/02-profile-and-nodes.md) |
| **Сеть пользователя** | множество нод одного профиля, объединённых доверием и синхронизацией | [сеть пользователя](../06-network/01-overview.md) |
| **Node** (нода) | конкретная установка K-OS на устройстве, обладающая собственной криптографической identity | [профиль и ноды](../02-architecture/02-profile-and-nodes.md) |
| **Device node** | нода с системным UI: десктоп, ноутбук, телефон | [профиль и ноды](../02-architecture/02-profile-and-nodes.md) |
| **Cloud node** | headless-нода пользователя: постоянная доступность, хранение, маршрутизация | [облачная нода](../09-clients/04-cloud-node.md) |
| **Appliance node** | узел без ключей данных профиля, владеющий подключённым оборудованием | [профиль и ноды](../02-architecture/02-profile-and-nodes.md) |
| **Relay node** | узел без ключей профиля, ретранслирующий зашифрованные данные | [профиль и ноды](../02-architecture/02-profile-and-nodes.md) |
| **Политика хранения** | сколько состояния профиля нода держит: `full-mirror`, `working-set`, `system-only`; не влияет на доверие | [профиль и ноды](../02-architecture/02-profile-and-nodes.md) |
| **Enrollment** | подтверждённое человеком добавление новой ноды в профиль | [identity и доверие](../06-network/02-identity-and-trust.md) |
| **Control log** | подписанный журнал состава профиля, ролей и прав | [control log](../06-network/03-control-log.md) |

| Термин | Значение | Подробно |
|---|---|---|
| **Package** (пакет) | подписываемая и версионируемая единица установки | [модель приложения](../03-apps/01-app-model.md) |
| **Component** (компонент) | единица запуска внутри пакета со своим жизненным циклом | [модель приложения](../03-apps/01-app-model.md) |
| **Web UI** | компонент пользовательского интерфейса приложения | [frontend](../03-apps/04-frontend.md) |
| **Worker** | backend-компонент приложения, исполняемый в WebAssembly | [backend](../03-apps/05-backend-wasm.md) |
| **Command** | короткая операция пакета, вызываемая по запросу | [модель приложения](../03-apps/01-app-model.md) |
| **Manifest** | описание пакета: компоненты, права, активация, совместимость | [манифест](../03-apps/02-manifest.md) |
| **Installation** | запись в реестре профиля о том, что пакет установлен | [распространение](../03-apps/07-distribution.md) |
| **Placement** | решение о том, на какой ноде компонент может и должен исполняться | [размещение](../03-apps/08-placement-and-execution.md) |
| **Активная версия** | версия пакета, из которой запускаются его компоненты; одна на профиль | [распространение](../03-apps/07-distribution.md) |
| **Удержание версии** | запрет автоматической активации конкретной версии, сопровождающий откат | [распространение](../03-apps/07-distribution.md) |
| **Системный пакет** | пакет, поставляемый в комплекте со сборкой системы; отключаемый, но не удаляемый | [распространение](../03-apps/07-distribution.md) |
| **Издатель** | владелец ключа, которым подписаны версии пакета; ключ фиксируется при первой установке | [источники пакетов](../03-apps/11-package-sources.md) |
| **Фид** | подписанный издателем список версий его пакетов | [источники пакетов](../03-apps/11-package-sources.md) |
| **Каталог** | справочник пакетов и ссылок на фиды; не является авторитетом для содержимого | [источники пакетов](../03-apps/11-package-sources.md) |

## Слои системы

| Термин | Значение | Подробно |
|---|---|---|
| **Host adapter** | нижний платформозависимый слой, реализующий примитив ОС или устройства | [host adapters](../02-architecture/03-host-adapters.md) |
| **Driver / resource broker** | слой владения ресурсом: мультиплексирование, очереди, квоты, handles | [drivers](../02-architecture/04-drivers.md) |
| **Service** | системная функция поверх драйверов и других сервисов | [services](../02-architecture/05-services.md) |
| **Control plane** | компоненты, от которых зависит сама проверка прав, и потому не подлежащие проверке прав | [services](../02-architecture/05-services.md) |
| **Platform extension package** | отдельно устанавливаемое нативное расширение, добавляющее host adapter | [расширяемость](../02-architecture/08-extensibility.md) |
| **Protocol engine** | переносимая реализация протокола поверх сетевых примитивов: HTTP, WebSocket, MQTT | [базовый стек](../02-architecture/06-base-stack.md) |
| **Adapter descriptor** | объявление доступности, режимов и лимитов конкретного adapter | [host adapters](../02-architecture/03-host-adapters.md) |
| **Демон** | процесс ядра ноды, живущий независимо от открытых окон | [десктопный клиент](../09-clients/02-desktop.md) |

Устаревшее название: **platform provider** — заменено на **host adapter**, в новых
документах и коде не используется. В разговорной речи означает то же самое.

## Права

| Термин | Значение | Подробно |
|---|---|---|
| **Capability** | ограниченное право выполнить класс операций | [модель прав](../04-capabilities/01-model.md) |
| **Permission** | право, запрошенное пакетом в манифесте | [модель прав](../04-capabilities/01-model.md) |
| **Grant** | право, подтверждённое пользователем или политикой на конкретной ноде | [модель прав](../04-capabilities/01-model.md) |
| **Handle** | непрозрачная ссылка на ресурс, ограниченная владельцем и временем жизни | [модель прав](../04-capabilities/01-model.md) |
| **Delegation** | явно ограниченная передача права на выполнение операции другой ноде | [делегирование](../06-network/06-rpc-and-delegation.md) |
| **Quota** | ограничение объёма использования уже выданного права | [каталог capabilities](../04-capabilities/02-catalog/00-index.md) |

## Данные

| Термин | Значение | Подробно |
|---|---|---|
| **Namespace** | логическая область хранения состояния приложения | [модель состояния](../05-storage/01-state-model.md) |
| **Replicated state** | состояние, синхронизируемое между нодами профиля | [репликация](../06-network/07-replication.md) |
| **Device-local state** | состояние, принадлежащее конкретной ноде и не реплицируемое | [модель состояния](../05-storage/01-state-model.md) |
| **VFS** | единое платформонезависимое пространство имён файлов профиля | [VFS](../05-storage/03-vfs.md) |
| **Blob** | неизменяемое содержимое, адресуемое хешем | [blob store](../05-storage/04-blobs-and-materialization.md) |
| **Материализация** | появление содержимого файла физически на конкретной ноде | [blob store](../05-storage/04-blobs-and-materialization.md) |
| **Selective sync** | политика, определяющая, какое содержимое хранится на какой ноде | [blob store](../05-storage/04-blobs-and-materialization.md) |
| **Volume** | поддерево VFS с собственным списком нод, хранящих его содержимое | [VFS](../05-storage/03-vfs.md) |
| **min-replicas** | минимальное число нод, хранящих содержимое; инвариант сохранности | [VFS](../05-storage/03-vfs.md) |
| **Владелец данных** | пользователь, пакет или система; ровно один у каждой единицы хранения | [мусор и квоты](../05-storage/05-garbage-and-quotas.md) |
| **Корзина профиля** | `/sys/trash/`: удалённые записи, восстановимые в пределах срока хранения | [мусор и квоты](../05-storage/05-garbage-and-quotas.md) |
| **Op log** | журнал реплицируемых операций | [репликация](../06-network/07-replication.md) |
| **Открытый кеш артефактов** | анонимная раздача публичного неизменяемого содержимого нодам других пользователей; отдельный пул, не входящий в состояние профиля | [открытый кеш](../06-network/11-public-artifact-cache.md) |

## Распределённая работа

| Термин | Значение | Подробно |
|---|---|---|
| **HLC** | hybrid logical clock, отметка для упорядочивания при разрешении конфликтов | [модель времени](../06-network/05-time.md) |
| **Version vector** | структура для выражения причинности изменений | [репликация](../06-network/07-replication.md) |
| **Lease** | временное разрешение на единоличное владение или фоновую работу | [координация](../06-network/08-coordination.md) |
| **Fencing token** | монотонный счётчик, защищающий внешний эффект от устаревшего владельца | [координация](../06-network/08-coordination.md) |
| **Execution scope** | требуемая кардинальность исполнения задачи в пределах профиля | [размещение](../03-apps/08-placement-and-execution.md) |
| **Экспорт API** | объявленный приложением набор методов, вызываемых с других нод и связанными пользователями без открытия порта | [базовый стек](../02-architecture/06-base-stack.md) |
| **Notification coordinator** | нода, решающая, какое уведомление и куда доставить | [события и push](../03-apps/10-events-and-push.md) |
| **Realtime-канал** | поток доставки без обещания сохранности, для управления и показаний | [realtime](../03-apps/09-realtime.md) |

## Взаимодействие пользователей и устройства

| Термин | Значение | Подробно |
|---|---|---|
| **Связывание сетей** | установление доверия между сетями двух пользователей | [взаимодействие пользователей](../07-federation/01-model.md) |
| **Публичная идентичность профиля** | ключ, которым пользователь известен связанным пользователям; не меняется при смене устройств | [взаимодействие пользователей](../07-federation/01-model.md) |
| **Membership roster** | подписанный список нод, уполномоченных действовать от имени профиля перед связанным пользователем | [взаимодействие пользователей](../07-federation/01-model.md) |
| **Share** | предоставление доступа к файлу, папке или устройству без передачи владения | [обмен](../07-federation/02-sharing.md) |
| **Подключённое устройство** | внешнее оборудование, доступное через конкретную ноду | [устройства и IoT](../08-devices/01-model.md) |
| **Device ID** | стабильный идентификатор подключённого устройства, не зависящий от порта | [устройства и IoT](../08-devices/01-model.md) |
| **Trait** | типовая возможность устройства с определённой семантикой: `switch`, `numeric-sensor` и подобные | [устройства и IoT](../08-devices/01-model.md) |
| **Bootstrap-узел** | публичный узел, помогающий нодам находить адреса друг друга и раздающий снимки каталогов приложений | [bootstrap-обнаружение](../12-future/01-bootstrap-discovery.md) |
