# Жизненный цикл компонентов

Статус: перенесено из прежних документов, требует ревизии.  
Назначение: описать активацию, deadline, отмену и завершение компонентов приложения.

Связанные документы: [модель приложения](./01-app-model.md), [размещение и исполнение](./08-placement-and-execution.md).


| Компонент | Жизненный цикл |
|---|---|
| `web-ui` | Пока существует view приложения в окне устройства |
| `worker` | От события до завершения обработчика |
| `background-worker` | Пока активна задача и runtime lease |
| `command` | Один запрос — одно ограниченное выполнение |
| `system-service` | Управляется ядром |

Пример фонового исполнения:

```text
Событие
   ↓
Runtime проверяет manifest и permissions
   ↓
Запускает worker
   ↓
Worker запрашивает background lease при необходимости
   ↓
Выполняет работу и сохраняет checkpoint
   ↓
Завершается или возобновляется по следующему событию
```

Каждое выполнение получает deadline и cancellation token. Принудительная остановка компонента не должна повреждать подтверждённое состояние.
