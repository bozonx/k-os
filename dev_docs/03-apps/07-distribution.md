# Распространение и установка приложений

Статус: перенесено из прежних документов, требует ревизии.  
Назначение: описать установку как операцию над реплицируемым состоянием, материализацию артефактов, обновление и откат.

Связанные документы: [манифест](./02-manifest.md), [репликация](../06-network/07-replication.md), [blob store](../05-storage/04-blobs-and-materialization.md), [мусор и квоты](../05-storage/05-garbage-and-quotas.md).


```text
package artifacts   immutable blobs, адресуемые хешем
package registry    реплицируемое состояние профиля
installation        запись в registry, а не копирование файлов
materialization     загрузка артефактов на конкретный node
```

Установка приложения — операция над replicated state. Она немедленно видна всем nodes; артефакты подтягиваются каждым node по мере необходимости запуска компонента.

Обновление создаёт новую версию: артефакты неизменяемы, поэтому старая и новая версия сосуществуют, а rollback является переключением активной версии.

Расширение permissions при обновлении не активируется автоматически. Новая версия переходит в состояние `pending-grant` и не запускается ни на одном node, пока пользователь не подтвердит изменение. Подтверждение — запись в control log.

Подпись пакета проверяется при установке и при материализации на каждом node отдельно.

## Удаление

Удаление симметрично установке и потому тоже является операцией над состоянием, а не над файлами. Существуют **две разные операции**, и объединять их запрещено:

| Операция | Область | Что происходит |
|---|---|---|
| убрать с этого устройства | одна нода | дематериализуются артефакты, удаляются `local`, `cache`, `tmp` и производные индексы; запись в registry не меняется |
| удалить из профиля | весь профиль | пакет исключается из registry, реплицируемые данные и файлы уходят в корзину на всех нодах |

Первая операция обратима и данных не теряет: пакет остаётся установленным в профиле и материализуется снова при необходимости. Вторая является изменением desired state профиля и распространяется на все ноды.

Смешение этих операций в одно действие приводит к тому, что освобождение места на телефоне уничтожает данные на десктопе. Правила уборки, сроки хранения и судьба файлов, записанных приложением в `/user/`, — в [мусоре и квотах](../05-storage/05-garbage-and-quotas.md).
