- песочница инкапсулирует токен который передается драйверам, для приложения или сервиса все выглядит прозрачно

- запрещено использовать io из самого nodejs

## API открытый для приложений
- services - доступ к другим сервисам и они уже сами управляют правами
- apps - доступ к другим приложениям
- drivers - получение инстансов для доступа к драйверам. Токен доступа инкапсулилируется
- localFiles - локальные файлы приложения с полным доступом но ограниченные с доступом выше
- syncFiles - синхронизируемые файлы приложения
- tmpFiles - локальные временные приложения файлы с полным доступом
- fileSystem - доступ к рут файловой системе , включая внешние папки , можно как запросить отдельную папку, так и полный доступ
- localDb, syncDb, cache - базы данные для конкретного приложения

## Функциональный подход для приложений
- дается контекст с которым работают все функции приложения
- нужно только отдать объект с методами onInit, onStart, onStop, afterInstall, beforeUninstall, onFreeze, onUnfreeze и во все их передется одинаковый контекст и дальше уже сам разработчик решает что с этим всем делать, может применять разные подходы как синглтоны так и функциональное программирование
