## Управление HTML элементом
- кастомные классы пользователя. тут же автоматически добаввляется уникальное название элемента, например div1, list1, list-item
- классы лэйаута - из tailwind. Но не используются цвета
- темы. Разбиты по темам - темная, светлая и др. выбираешь  css параметр и в его значении выбираешь переменную темы. приимущественно это должны быть цвета, но могут быть и другие стили
- стили. они нужны для управления через стейт. выбираешь css параметр , единицу измерения и выбираешь переменную стейта или компаунд свойство. тут не делаешь никаких вычислений, если они нужны то вычисляешь свойства отдельно либо в компаунде
- атрибуты. выбираешь доступные атрибуты для этого элемента или кастомный. выбираешь тип значения: шаблон, переменная, статическое(по сути строка)
- события. пишем название и параметры что он прехватывает , prevent и тд. потом событие с этим названием можно выбрать в обработчике или нескольких
- model . устанавливаешь одну модеь на элемены формы. просто выбираешь из списка стейта

## Управление компонентом
- название. оно будет и именем файла и назвванием компонента
- устанавливаешь props , типы значений и значения по умолчанию
- тоже делаешь со стейтом
- в стейте может быть компаунд, тогда вв нем можно писать выражения
- создаешь обработчики для кнопок и других событий, включая watch. каждому обаботчику указываешь что он обрабатывает - вотч, глобальные события, события html элементов
- обрабочики показываются по категориям на которые они наввешены - хуки onMount и тд, обработчики html элементов, глобальные обработчики
- уникальные стили в виде обычного css для особых случаев

## Общие ресурсы
- глобальые стили в видео просто css
- темы в виде переменных css. Палитра задана заранее, нужно только поменять цввет
- конфиг разработчика, неизменяемый в рантайме
- конфиг юзера (привязан к апи)
- сессия юзера (пока он залогинен)
- глобальный inMemory state
- api где все внешние запросы
