
## Root compositor

- Это главная входная точка для управления тайлами в виде главного тайла где будут окна и тайлов панелей
- В firefox будет 2 root композитора. 1й в левой панеле браузера который только рисует вертикальную панель librnet и 2й в основном окне браузера где будут дополнительные панели и главное окно компзитора
- панелей будет 2 типа : горизонтальная и вертикальная и может быть несколько вариантов каждого типа если они установлены в систему
- только он имеет связь с ws ui api
- всем остальным он передает функцию связи и вызывает их фю эмитируя канал
- оборачивает каналы для приложений жестко внедряя в запросы имя приложения для разрешения прав
- запросы от приложений жестко идут только на их api где контекст так же подставляет жестко имя приложения в запросы в драйверы
- приложение не может делать на фронтенде другие запросы. если ему нужен другой апи то он это делает уже на стороне сервера
- чтобы гарантировать что к api обращаеются только то окно которое разрешено пользователем будет сохраняться кукис с токеном сессии

## Panel compositor
- упраляет панелью
- посылает сигнал на переключение комнаты или десктопа и он пересылается на desktop compositor
- так же посылает сигнал на открытие приложение или переключение фокуса на него

## Desktop compositor
- Комнаты
- рабочие столы комнат
- виртуальные тайлы на рабочем столе
- плавающие окна
